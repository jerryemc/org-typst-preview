#+title: org-typst-preview
#+options: toc:2

Asynchronous native [[https://typst.app/docs/reference/math/][Typst math]] previews for Org mode, using the interface you
already know from ~org-latex-preview~.

[[https://github.com/roife/org-typst-preview/actions/workflows/test.yml][https://github.com/roife/org-typst-preview/actions/workflows/test.yml/badge.svg]]

* Why

Org recognizes ~$...$~ as a ~latex-fragment~.  That parser is useful even when
the contents use Typst instead of LaTeX.  This package keeps Org's parser,
commands, key bindings, colors, cache location, and image overlay conventions,
but replaces the synchronous LaTeX toolchain with an asynchronous Typst-to-SVG
renderer.

Write native Typst:

#+begin_src org
  Inline math: $sum_(i=1)^n i$.

  Display math uses Typst's spaces next to the delimiters:

  $ sum_(i=1)^n i = (n(n+1))/2 $
#+end_src

* Features

- Native Typst math inside ordinary Org ~$...$~ fragments.
- Drop-in command behavior for ~org-latex-preview~, including its prefix
  arguments and the standard ~C-c C-x C-l~ binding.
- Fully asynchronous rendering with a configurable concurrency limit.
- Content-addressed SVG cache and coalescing of identical in-flight jobs.
- Stale-result protection when a formula changes before compilation finishes.
- Foreground, background, and scale inherited from
  ~org-format-latex-options~.
- Cache location inherited from ~org-preview-latex-image-directory~.
- Optional idle auto-preview mode.
- Typst diagnostics attached to failed formulas and collected in a dedicated
  buffer.
- Temporary source files are created next to local Org files, allowing relative
  imports in ~org-typst-preview-preamble~, and removed after compilation.

* Requirements

- Emacs 28.1 or newer.
- Org 9.5 or newer.
- The [[https://typst.app/open-source/][Typst CLI]] available on ~exec-path~.
- Emacs built with SVG image support.

* Installation

** straight.el

#+begin_src emacs-lisp
  (use-package org-typst-preview
    :straight (:host github :repo "roife/org-typst-preview")
    :after org
    :hook (org-mode . org-typst-preview-mode))
#+end_src

With automatic re-rendering after edits:

#+begin_src emacs-lisp
  (use-package org-typst-preview
    :straight (:host github :repo "roife/org-typst-preview")
    :after org
    :hook (org-mode . org-typst-preview-auto-mode))
#+end_src

** package-vc

On Emacs 29 or newer:

#+begin_src emacs-lisp
  (unless (package-installed-p 'org-typst-preview)
    (package-vc-install
     '(org-typst-preview
       :url "https://github.com/roife/org-typst-preview")))
#+end_src

* Usage

Enable ~org-typst-preview-mode~ in an Org buffer.  The usual Org command now
uses Typst:

| Input                  | Action                         |
|------------------------+--------------------------------|
| ~C-c C-x C-l~          | Toggle formula at point        |
| ~C-c C-x C-l~          | Preview the active region      |
| ~C-u C-c C-x C-l~      | Clear the current section      |
| ~C-u C-u C-c C-x C-l~  | Preview the whole buffer       |
| ~C-u C-u C-u ...~      | Clear the whole buffer         |

The following commands are also available:

- ~M-x org-typst-preview~
- ~M-x org-typst-preview-clear~
- ~M-x org-typst-preview-refresh-buffer~
- ~M-x org-typst-preview-show-errors~

Completed previews use Org's ~org-latex-overlay~ type.  Consequently,
~org-clear-latex-preview~ can clear them too when called outside the minor-mode
command remapping.

* Configuration

The package deliberately reuses these Org settings:

#+begin_src emacs-lisp
  ;; Used when the package-specific options below are nil.
  (plist-put org-format-latex-options :scale 1.2)
  (setq org-preview-latex-image-directory
        (expand-file-name "org/formulas/" user-emacs-directory))
#+end_src

Package-specific options include:

#+begin_src emacs-lisp
  (setq org-typst-preview-max-processes 4
        ;; nil means inherit Org's :scale option.
        org-typst-preview-scale nil
        org-typst-preview-font-size 11.0
        ;; nil means reuse org-preview-latex-image-directory.
        org-typst-preview-image-directory nil
        org-typst-preview-preamble
        "#import \"@preview/physica:0.9.5\": *")
#+end_src

When a relative file is imported by the preamble, it is resolved relative to
the Org buffer directory because temporary Typst source files are created
there.

* Delimiters and Org parsing

The recommended forms are exactly Typst's native delimiters:

#+begin_src org
  Inline: $integral_0^1 x^2 dif x$

  Block: $ integral_0^1 x^2 dif x = 1/3 $
#+end_src

For migration, ~$$...$$~, ~\(...\)~, and ~\[...\]~ are normalized to Typst
delimiters before rendering.  They are not recommended for new documents.

Org still names these syntax nodes ~latex-fragment~ internally.  The name is an
implementation detail; the contents passed to this package are Typst.

* Export

This package changes previews only.  It intentionally does not change Org's
export backends.  To export the same native Typst formulas through
[[https://github.com/jmpunkt/ox-typst][ox-typst]], select its naive fragment conversion so the formula text is passed
through unchanged:

#+begin_src emacs-lisp
  (setq org-typst-from-latex-fragment #'org-typst-from-latex-with-naive
        org-typst-from-latex-environment #'org-typst-from-latex-with-naive)
#+end_src

* Security

Previewing invokes a local compiler.  The package refuses to run when Org marks
content as untrusted.  Setting ~org-typst-preview-when-risky~ to non-nil opts
out of that protection.

* Development

Run the unit and compiler integration tests with:

#+begin_src shell
  make check
#+end_src

Integration tests are skipped when the Typst executable is unavailable.
